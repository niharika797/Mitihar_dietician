### Tier Logic
```python
def _tier(usage: int) -> dict:
    if usage <= 100:   fee = 250_000
    elif usage <= 200: fee = 300_000
    elif usage <= 400: fee = 400_000
    else:              fee = 500_000
    return {"annual_fee": fee, "differential_owed": fee - 250_000}
```
