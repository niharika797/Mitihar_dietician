ITEM 1 — food_allergies validation fix (schemas/patients.py)

  NEW IMPORT: pydantic BaseModel + Field added to admin.py imports.
  CLASS: BillingMarkPaidRequest(amount, notes, period) — inline in router.

  ADDED: @limiter.limit("10/minute") on POST /auth/register

  ADDED: @limiter.limit("30/minute") on POST /progress/log/water, steps, weight, activity
  All 5 endpoints also got `request: Request` param injected (required by slowapi)
  ADDED: pyotp to requirements.txt

ITEM 4 — MFA (TOTP) for doctor + admin
  NEW FILE: app/services/mfa_service.py
    generate_mfa_secret() — pyotp.random_base32()
    get_totp_uri(secret, email) — provisioning_uri for QR code
    verify_totp(secret, code) — valid_window=1 (±30s clock drift tolerance)
  NEW ENDPOINTS in auth.py:
    POST /auth/doctor/login    — mfa_enabled=False → full JWT (unchanged behaviour)
                                  mfa_enabled=True  → partial 5-min token
    POST /auth/doctor/mfa-login    — partial token + TOTP → full JWT
    POST /auth/doctor/mfa-setup    — generate secret, return otpauth:// URI
    POST /auth/doctor/mfa-confirm  — verify live code, set mfa_enabled=True
    POST /auth/doctor/mfa-disable  — requires valid TOTP, clears secret
    POST /auth/admin/login     — same fork as doctor
    POST /auth/admin/mfa-login     — same pattern
    POST /auth/admin/mfa-setup     — same pattern
    POST /auth/admin/mfa-confirm   — same pattern
    POST /auth/admin/mfa-disable   — same pattern
  BACKWARD COMPAT: all existing test accounts have mfa_enabled=False; 95 tests unaffected
